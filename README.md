# Tonigma Documentation

This repository is the central publication home for the Tonigma project.

Start with the [publication index](index.md) for project-wide legal, protocol, security, monitoring, developer, and performance documentation. Component-specific documents remain in their owning repositories and are linked from that index.

The repository-local documents are the canonical source for the Tonigma White Paper, Terms of Service, Privacy Notice, and Monitoring Packet.
