# Tonigma Documentation

This repository is the central publication home for the Tonigma project.

Start with the [publication index](index.md) for project-wide protocol, privacy, security, monitoring, developer, and performance documentation. Component-specific documents remain in their owning repositories and are linked from that index.

The repository-local documents are the canonical source for the Tonigma White Paper, Privacy And Disclosure System Policy, and Monitoring Packet.

This repository is a technical and policy reference, not a collection of usage guides. Usage guidance belongs in the README of the component that provides the relevant interface.

Publication-document eligibility and index maintenance are defined in the [Publication Index Policy](INDEX_POLICY.md).
